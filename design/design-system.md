# GS Gacuba Design System & Token Guide

## 1. Brand Philosophy
Groupe Scolaire Gacuba II A represents academic excellence, discipline, and community development in Rubavu, Rwanda. The visual system marries prestigious academic heritage (Navy and Slate) with energetic optimism (Institutional Amber/Orange and Warm Sand).

## 2. Token Definitions

### Color Palette
- **Primary Amber (`#FF8C00`)**: Primary action button, active navigation indicator, high-priority highlights.
- **Navy (`#211F54`)**: Primary header typography, hero banners, dark cards, footer background.
- **Dark Navy (`#19213D`)**: Secondary dark surface contrast, card headers.
- **Slate (`#353E5C`)**: Subheadings, active icons, secondary borders.
- **Muted Gray (`#6D758F`)**: Body paragraphs, subtle metadata, inactive icons.
- **Warm Sand (`#C3B091`)**: Badges, prestige tags, academic honors.
- **Warm Sand Light (`#FBF9F5`)**: Alternating section background.

### Typography
- **Headings Font**: `Inter`, `Manrope`, sans-serif (Weights: 600, 700, 800)
- **Body Font**: `Inter`, sans-serif (Weights: 400, 500)

### Spacing Scale
- `xs`: 4px | `sm`: 8px | `md`: 16px | `lg`: 24px | `xl`: 32px | `2xl`: 48px | `3xl`: 64px
